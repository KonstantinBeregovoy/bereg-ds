# Colors

Semantic tokens, named by role. They point to the primitive palette (`--prim-*`), which components never use directly.
Dark is the default theme. The light theme is optional and uses the same names (see Foundations / Themes).

Text pairs are 7:1 or more in both themes (WCAG 1.4.6). `--line` is for decorative lines only.
Borders that identify an interactive element use `--line-strong` (3:1 or more, WCAG 1.4.11).
Alpha colors (grid, selection, shadows) are shown over the page background.
