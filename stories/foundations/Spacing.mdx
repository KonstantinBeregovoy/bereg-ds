# Spacing and radii

Scale of 4. The token name is the multiplier: `--space-3` = 3 × 4 = 12px (0.75rem).

<SpacingScale />

**Radii:** `--radius-sm` 2px (default for everything), `--radius-md` 4px, `--radius-lg` 8px (images in articles).

**Outside the scale on purpose:** strokes 1/2/3px, corner ticks 11/22px, the blueprint grid 24/120px,
breakpoints 640/760px (use `40em` and `47.5em` in media queries).
